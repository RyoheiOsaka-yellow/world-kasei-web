# プロトタイプ説明動画（自動収録）

`world-kasei---wintec-pos` のプロトタイプを実際に操作しながら、テロップ・操作ガイド付きの説明動画（1920×1080 / 30fps / MP4）を自動で収録します。
サイトの内容を変更したら、コマンド1つで動画を作り直せます。

## 使い方

```bash
# 初回のみ（アプリ側・収録側の依存関係）
(cd ../world-kasei---wintec-pos && npm install)
npm install
npx playwright install chromium   # ブラウザ未導入の環境のみ

# 収録 → 仕上げ
npm run video
```

`out/` に以下が出力されます。

| ファイル | 内容 |
| --- | --- |
| `wintec-pos-prototype-walkthrough.mp4` | 完成動画（先頭・末尾フェード、Web 再生向け faststart） |
| `captions.srt` | テロップの字幕ファイル（翻訳・ナレーション原稿のたたき台に） |
| `chapters.txt` | チャプター一覧（YouTube の概要欄にそのまま貼れる形式） |
| `raw.mp4` | 仕上げ前の収録データ |

## 構成

| ファイル | 役割 |
| --- | --- |
| `record.mjs` | シナリオ本体。アプリを起動し、Playwright で操作しながら CDP スクリーンキャストを ffmpeg に流し込む |
| `overlay.js` | ページに注入する演出レイヤー（テロップ、カーソル、クリック波紋、ハイライト枠、章扉） |
| `stage.html` | スマートフォン表示のデモ用画面（端末フレーム＋操作手順パネル） |
| `assets.mjs` | Tailwind CDN・フォント・画像を curl でキャッシュして配信（収録ごとに見た目がぶれないように） |
| `encode.sh` | 収録データを配布用 MP4 に仕上げる |

## 調整のしかた

- **テロップの文言・順番**：`record.mjs` の `scenario()` を編集します。`d.say(ラベル, 本文)` で表示し、文字数に応じて自動で読み時間を確保します。`<em>…</em>` は強調色、`<small>…</small>` は補足行になります。
- **テロップの表示時間**：`readMs()`（基本 0.9 秒＋1文字あたり 0.115 秒）。
- **デザイン**：`overlay.js` 冒頭の CSS（ブランドカラー `#003366` / `#F5A623`）。
- **滑らかさ**：1080p の取り込みは 25fps 前後が上限のため、ページ内の時間を 1/2 倍速で進めて収録し、書き出し時に等速へ戻しています（`SLOWMO=2`）。収録には動画の約2倍の時間がかかります。
